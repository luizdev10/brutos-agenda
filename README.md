# Brutos Agenda

Sistema web de agendamento online para a **Barbearia Brutos** (estabelecimento fictício), desenvolvido como Experiência Prática 3 de Projeto de Software (Análise e Desenvolvimento de Sistemas).

O objetivo é reduzir horários duplicados (overbooking) e faltas sem aviso, permitindo que o cliente agende pelo celular, sem instalar aplicativo.

O código do MVP está na branch `feat/mvp-agendamento` e entra na `main` por Pull Request.
